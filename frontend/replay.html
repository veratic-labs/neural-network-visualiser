This page replays a recorded run from plain static files: no Python, no server, no WebSocket. Play, Pause, Previous and Next move through the recorded checkpoints, and the timeline's labels are real optimiser steps. Full mode draws every connection of the initial model recorded at Step 0 and stays static, because later full-network weights were not recorded; Partial mode updates the fixed recorded selection at every checkpoint. Nothing is interpolated: every number shown is the number stored in the recording. The live mode is still index.html with the Python backend running.
